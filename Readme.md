# Проект Mentee Power

Система для отслеживания прогресса участников менторской программы.

## Quick Start

### Запуск приложения
./gradlew run

### Запуск тестов
./gradlew test

## Описание пакета ru.mentee.power
Пакет реализует базовую модель для отслеживания готовности участников менторской программы к спринтам. Основной компонент — неизменяемая запись (record) MenteeProgress, содержащая ключевые метрики прогресса.

### Ключевые компоненты
#### 1. Запись MenteeProgress
Неизменяемый контейнер данных о готовности менти к спринту. Содержит три поля:

menteeName (String) — имя участника программы;

sprintNumber (int) — номер текущего спринта;

plannedHoursPerWeek (int) — запланированные часы работы в неделю.

#### Публичные методы:

readyForSprint():
Проверяет готовность участника к спринту. Возвращает true, если plannedHoursPerWeek ≥ 3.
Логика: минимальный порог в 3 часа считается достаточным для продуктивной работы в спринте.

summary():
Формирует сводную строку в формате:
"Sprint <номер> → <имя>: planned <часы> h".
Пример: Sprint 2 → Vlad: planned 10 h.

#### 2. Класс ProgressDemo
Демонстрационный пример использования модели. Показывает:

создание экземпляра MenteeProgress;

вызов метода summary() для вывода сводки;

проверку готовности к спринту через readyForSprint().

### Принципы работы
Иммутабельность: MenteeProgress — запись (record), поэтому её состояние нельзя изменить после создания. Для обновления данных требуется создание нового экземпляра.

Минимализм: логика ограничена базовыми проверками без внешних зависимостей.

Читаемость: метод summary() формирует человеко‑понятный вывод.

### Пример использования
java
MenteeProgress progress = new MenteeProgress("Vlad", 2, 10);
System.out.println(progress.summary());
// Вывод: Sprint 2 → Vlad: planned 10 h

if (progress.readyForSprint()) {
System.out.println("Status: sprint ready");
} else {
System.out.println("Status: backlog first");
}
// Вывод: Status: sprint ready


### Зависимости
Пакет использует только стандартные классы Java (нет внешних библиотек).

### Назначение в системе
Пакет предназначен для:

интеграции в API для передачи данных о готовности к спринтам;

генерации отчётов о загрузке участников;

реализации бизнес‑правил распределения нагрузки в менторской программе.
